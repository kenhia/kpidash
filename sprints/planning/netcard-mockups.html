Network-health card, four looks

Each card is drawn at rpi53's real 2×1 cell, 1264×628 px, in Fortune's slot. The state buttons drive all four at once so the degraded reads can be compared side by side. Text sizes are the Montserrat sizes kpidash already ships (14–48).

State Scale

A · Fabric map stylised topology, links carry the state

Glance

All spokes teal and the uplink lavender means healthy. A yellow spoke is a host on its 1G backup. A red dashed uplink with every host still teal is the korg:4055 trap, drawn as what it is.

LVGL cost

  • Rounded rects, lv_line spokes (width per speed), labels. No chart, no canvas.
  • Static between polls; nothing animates. Cheapest of the four.
  • Dashed lines are not native in LVGL 9.2; the "down" spoke is a run of short lv_line segments.

Fields it needs

  • Per host: active leg (10g / 5g / 1g / down), negotiated speed, Link Failure Count + 24 h delta, RX errors 24 h delta, feed age.
  • Per host reachability: UDM, any peer, Internet (ok / fail), WAN RTT.
  • Fabric: uplink state (derived: no host reaches UDM while peers are fine).
  • Does not need throughput.

B · Rail one column per host under a fabric backplane, with throughput

Glance

The status word and the rail's colour carry it. A column's numeral turns yellow or red on its own, and the sparkline shows whether the link has been busy or flat.

LVGL cost

  • Five 60-point area sparklines: either lv_chart or the dev_graph line path, about 300 line tasks per refresh, well under one dev graph.
  • Pills are rounded rects with labels.
  • Needs the 48-pt bold font, which the repo already generates.

Fields it needs

  • Everything in A, plus per host: 10G NIC bytes/s (tx+rx), 60-sample history kept by the renderer, not the feed.
  • UDM RTT, WAN RTT, uplink load (sum of host traffic that leaves the fabric, if the producer can tell).

C · Reach rings hosts as rays through fabric, gateway and Internet rings

Glance

Every ray reaches the outer ring: healthy. Uplink lost: every ray stops at the first ring. WAN down: they stop at the second. A host on 1G is a yellow ray. The ring a ray stops at is the diagnosis, which the other three only say in words.

LVGL cost

  • Three lv_arc rings, five rays as lv_line, nodes as circles (rounded rects with radius = half size), labels.
  • The sweep is one rotating arc animated by lv_anim; drop it if 30 fps on the Pi dips. Everything else is static.

Fields it needs

  • Same as A. Throughput optional (could set ray thickness).
  • The ray stop point is computed on the panel from the three reachability booleans, so the feed stays small.

D · Pulse big verdict, host chips with live load, an hour-long heartbeat trace

Glance

The verdict word and its colour. The trace tells the story of the last hour: a failover is a red tick with the host's initial, so a flapping link shows as a comb of ticks even when the numeral says 10G right now.

LVGL cost

  • One 120-point lv_chart with area fill, event ticks as small rects, the scan line is one animated lv_line.
  • Chip load bars are lv_bar.
  • Comparable to one dev graph; fine.

Fields it needs

  • Everything in B, plus a failover event log (host, time, from→to leg) or the renderer diffs LFC between polls to synthesise ticks.
  • Aggregate fabric throughput per sample (sum of host 10G bytes/s).
